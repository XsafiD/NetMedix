Tentang NetMedix

NetMedix adalah sistem pakar berbasis web yang dirancang untuk membantu mendiagnosis masalah jaringan komputer secara cepat dan akurat. Sistem ini menggunakan metode Certainty Factor (CF) untuk menghitung tingkat keyakinan diagnosis berdasarkan kecocokan gejala yang dipilih user dengan aturan IF-THEN pada knowledge base.

Dibangun sebagai tugas UAS mata kuliah Sistem Cerdas, NetMedix mampu mengidentifikasi 15 masalah jaringan berdasarkan 40 gejala yang dikelompokkan dalam 7 kategori, menggunakan 15 aturan IF-THEN yang telah divalidasi.

Diagnosis Cepat

Cukup pilih gejala yang dialami dan tentukan tingkat keyakinan — hasil ditampilkan dalam hitungan detik.

Akurat & Terukur

Setiap diagnosis disertai nilai Certainty Factor (CF) yang menunjukkan tingkat keyakinan secara kuantitatif.

Knowledge Base Lengkap

15 masalah jaringan, 40 gejala, dan 15 aturan yang mencakup konektivitas, DNS, DHCP, WiFi, performa, keamanan, hingga hardware.

Metode Inferensi

Certainty Factor (CF)

Metode Certainty Factor diperkenalkan oleh Shortliffe & Buchanan (1975) dalam sistem MYCIN. CF digunakan untuk mengukur tingkat keyakinan terhadap sebuah kesimpulan, memperhitungkan ketidakpastian dalam penalaran ahli manusia.

Alur Perhitungan CF

Input Gejala Fakta dari user
→
Cocokkan Aturan IF gejala THEN masalah
→
Hitung CF Certainty Factor
→
Diagnosis Semua kandidat lolos filter

Contoh Aturan IF-THEN

// R01: Tidak Ada Koneksi Jaringan

IF G01 (Tidak ada koneksi sama sekali)

AND G20 (ipconfig menunjukkan Media Disconnected)

AND G26 (Kabel LAN tidak terdeteksi)

THEN P01 = Tidak Ada Koneksi Jaringan

// R03: DNS Resolution Failure

IF G04 (Bisa ping IP tapi tidak bisa ping domain)

AND G21 (nslookup gagal resolve)

AND G24 (Error "DNS Server Not Responding")

THEN P03 = DNS Resolution Failure

MB (Measure of Belief)

Ukuran kepercayaan terhadap hipotesis berdasarkan evidence (gejala). Nilai antara 0 dan 1.

MD (Measure of Disbelief)

Ukuran ketidakpercayaan terhadap hipotesis berdasarkan evidence. Nilai antara 0 dan 1.

CF (Certainty Factor)

Selisih antara MB dan MD. Nilai antara -1 (pasti tidak) hingga 1 (pasti ya).

Rumus Utama

1. CF Rule (CF Hipotesis berdasarkan Evidence)

CF(H,E) = MB(H,E) - MD(H,E)

Selisih antara Measure of Belief dan Measure of Disbelief untuk suatu evidence.

2. CF Evidence (CF berdasarkan keyakinan user)

CF_evidence = CF_user × CF(H,E)

Mengalikan tingkat keyakinan user (CF_user) dengan CF rule untuk mendapatkan CF evidence per gejala.

3. CF Combine (Kombinasi beberapa evidence)

CF_combine = CF1 + CF2 × (1 - CF1)

Menggabungkan CF dari beberapa evidence secara bertahap untuk mendapatkan CF akhir diagnosis.

Contoh Perhitungan

Skenario: Koneksi Internet Terputus (P02)

Input user: G02 (CF_user = 0.8), G03 (CF_user = 1.0), G28 (CF_user = 0.6)

/* Step 1: Hitung CF Rule per gejala */ G02: CF(H,E) = MB(0.90) - MD(0.05) = 0.85 G03: CF(H,E) = MB(0.95) - MD(0.05) = 0.90 G28: CF(H,E) = MB(0.80) - MD(0.05) = 0.75 /* Step 2: Hitung CF Evidence per gejala */ G02: CF_evidence = 0.8 × 0.85 = 0.68 G03: CF_evidence = 1.0 × 0.90 = 0.90 G28: CF_evidence = 0.6 × 0.75 = 0.45 /* Step 3: Kombinasi CF secara bertahap */ Combine 1: 0.68 + 0.90 × (1 - 0.68) = 0.68 + 0.288 = 0.9680 Combine 2: 0.9680 + 0.45 × (1 - 0.9680) = 0.9680 + 0.0144 = 0.9824 /* Hasil Akhir */ CF P02 = 98.24% → Sangat Yakin

Interpretasi Nilai CF

Rentang CF Label Keterangan
0.80 – 1.00 Sangat Yakin Diagnosis sangat kuat, gejala sangat cocok
0.60 – 0.79 Cukup Yakin Diagnosis cukup kuat, mayoritas gejala cocok
0.40 – 0.59 Kemungkinan Ada kemungkinan, perlu gejala tambahan
0.20 – 0.39 Kurang Yakin Diagnosis lemah, gejala kurang spesifik
< 0.20 Tidak Yakin Diagnosis sangat lemah, hampir tidak ada kecocokan

Arsitektur

Arsitektur Sistem

NetMedix mengikuti arsitektur sistem pakar klasik yang terdiri dari beberapa komponen utama yang saling berinteraksi untuk menghasilkan diagnosis.

User Interface

Inference Engine

Certainty Factor (CF)

Knowledge Base

JSON Files (problems, symptoms, rules)

Working Memory

Gejala terpilih + CF user values

User Interface

Antarmuka web berbasis Flask dengan template Jinja2. Pengguna memilih gejala melalui form interaktif, menentukan tingkat keyakinan, dan melihat hasil diagnosis lengkap dengan detail perhitungan CF.

Inference Engine

Mesin inferensi yang mencocokkan gejala yang dipilih user dengan aturan IF-THEN pada knowledge base, lalu menghitung tingkat keyakinan menggunakan Certainty Factor. Menghasilkan semua kandidat diagnosis yang lolos filter ≥ 2 gejala relevan, diurutkan berdasarkan nilai CF tertinggi.

Knowledge Base

Basis pengetahuan yang tersimpan dalam file JSON: 15 masalah jaringan (P01-P15), 40 gejala (G01-G40), dan 15 aturan IF-THEN (R01-R15) dengan nilai CF pakar per gejala. Dapat dikelola melalui Admin Panel.

Working Memory

Memori kerja yang menyimpan fakta sementara selama proses inferensi berlangsung — yaitu gejala yang dipilih user beserta nilai keyakinan (CF user) yang diberikan.
